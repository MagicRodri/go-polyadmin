# Examples

- [`fiber/`](fiber/) — reference Fiber application exercising the full
  feature set: `User` and `Organization` (a foreign key relation), with
  CRUD, search, filters, a dashboard, authentication/authorization,
  actions, custom pages, inlines, and CSV/XLSX export. Runnable, and
  doubles as an integration test.

The Python implementation ships an equivalent FastAPI app against the
same domain shape, in its own repository:
[MagicRodri/polyadmin](https://github.com/MagicRodri/polyadmin).
